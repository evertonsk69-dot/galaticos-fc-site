# GALÁTICOS FUTEBOL CLUBE — SITE

Site responsivo em HTML, CSS e JavaScript puro.

## Arquivos
- index.html — estrutura do site
- style.css — visual vermelho/preto
- script.js — dados, estatísticas, calendário, busca do elenco e filtros
- logo-galaticos.png — escudo enviado
- vestiario-galaticos.png — imagem de fundo enviada

## Como usar
1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. Para atualizar os números, abra `script.js`.
4. Na seção `DADOS DO SITE — EDITE AQUI`, altere:
   - jogos, vitórias, gols e aproveitamento;
   - artilheiros e quantidade de gols;
   - assistências;
   - calendário;
   - elenco.

Não é necessário instalar programa ou servidor para testar localmente.

## Publicar grátis
Você pode publicar a pasta em serviços de hospedagem estática como GitHub Pages, Netlify ou Vercel.


## Redes sociais
Os botões de Instagram e YouTube já estão configurados para abrir os links oficiais em nova aba.

## Uniformes
Os caminhos `file:///E:/...` enviados são caminhos locais do seu computador. Eles não funcionam para visitantes do site. Envie as duas imagens dos uniformes no chat para que sejam incorporadas ao pacote e ao slider.

## Contatos
A seção de responsáveis está preparada com Everton e Henrique. Substitua os textos de contato pelo telefone/WhatsApp real no `index.html`.
